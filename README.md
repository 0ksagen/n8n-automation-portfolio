# n8n Automation Portfolio

A portfolio of practical automation and integration projects built with **n8n, REST APIs, OpenAI, Gmail and Google Sheets**.

## Projects

### 1. Gmail AI CRM

A workflow that:

- receives Gmail messages;
- normalizes sender, subject and message content;
- classifies messages as `ORDER`, `LEAD`, `QUESTION` or `OTHER`;
- validates complete orders with deterministic business rules;
- routes structured records into Google Sheets;
- prevents duplicate processing with Gmail message IDs;
- includes spam polling, retries, global error handling and loop protection.

**Stack:**  
`n8n` · `Gmail` · `OpenAI` · `Google Sheets` · `Structured Output`

### 3. CorelDRAW Laser Preflight Utility

A production-oriented automation utility for preparing laser-cutting layouts in CorelDRAW.
